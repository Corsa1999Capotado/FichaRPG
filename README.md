# FichaRPG

Aplicativo desktop para criar, gerenciar e organizar fichas de personagem de RPG.

## Download

Baixe a última versão para Windows na página de [Releases](https://github.com/Corsa1999Capotado/FichaRPG/releases/latest):

1. Baixe o arquivo `FichaRPG-Windows.zip`.
2. Extraia o conteúdo em uma pasta.
3. Execute `FichaRPG.exe`.

## Compilando a partir do código-fonte

Requisitos: Qt e CMake.

```
cmake -B build -S .
cmake --build build
```
